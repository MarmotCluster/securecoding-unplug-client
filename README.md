## Getting Started

### requirements

-   `node.js`&nbsp; v16.0 or newer.
-   `npm`&nbsp; v8.0 or newer.

### run it locally

```cmd
git clone https://github.com/MarmotCluster/securecoding-unplug-client.git
```

```cmd
cd securecoding-unplug-client
npm install
npm start
```
